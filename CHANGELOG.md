# Changelog

All notable changes to the **Status Quo** extension are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.3]

### Added

- Color swatches next to each preset in the color list
- New color picker panel with a hex field and a live status bar preview
- A current color that isn't one of the presets is shown at the top of the list

### Changed

- The current color is now highlighted in the list and pre-filled in both the
  color picker and the hex input

## [0.0.2]

### Added

- Initial release
- Custom status bar text, editable from the status bar or the Command Palette
- Eight preset colors plus custom hex input
- Reset to theme default
- Automatic black/white foreground based on background lightness
- All settings stored at workspace level only
